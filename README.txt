SOS Game (Linux) Installer Package

Contents:
- sos-x86_64.AppImage
- install_sos.sh
- uninstall_sos.sh
- assets/sos.svg

Install:
1) Open a terminal in this folder.
2) Run:
   sudo ./install_sos.sh

Uninstall:
1) Run:
   sudo ./uninstall_sos.sh

Notes:
- The app is installed to /opt/sos
- A desktop launcher is created in /usr/share/applications
